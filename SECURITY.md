# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues,
discussions or pull requests.

Instead, report them privately using GitHub's private vulnerability
reporting:

1. Go to <https://github.com/diffpy/diffpy.structure/security/advisories/new>
   (or open the **Security** tab of the repository and click
   **Report a vulnerability**).
2. Describe the problem, the versions affected, and the steps needed to
   reproduce it. A small example file or script is very helpful.

The report is visible only to you and the maintainers. If you cannot use
GitHub's private reporting, email the maintainer, Simon Billinge
(sbillinge@ucsb.edu), and ask for a private channel before sending any
details.

## What to expect

We will acknowledge the report, investigate it, and keep you informed in
the private advisory. Once a fix is released we will publish the advisory
and credit you, unless you prefer to remain anonymous.

## Supported versions

Security fixes are made to the latest release of `diffpy.structure`.
Please upgrade to the latest release before reporting a problem.
